# pyQtStyleSheets

Canonical Qt stylesheets for TinyStudio DCC UIs (Maya, Unreal, etc.).

Load via `genTools.uiUtils.load_qss()` or `studioUiUtils.load_qss()` — both resolve this folder through `GenTools/shared/studioFilePaths.py`.

Do not duplicate `.qss` files under MayaRepository or UnrealRepository.
